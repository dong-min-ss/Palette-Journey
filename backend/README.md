# 로컬 백엔드

Node24 이상에서 저장소 루트의 `npm.cmd start`로 실행한다.
주소는 http://127.0.0.1:3000 이며 외부 네트워크에는 바인딩하지 않는다.
SQLite 데이터는 backend/data/에 저장되고 Git에서 제외된다.

## 계정 식별

클라이언트는 암호학적 난수32바이트를 소문자 hex64자로 생성해 안전하게 보관하고,
모든 계정 API에 `Authorization: Bearer <토큰>` 헤더로 보낸다.
토큰은 URL에 넣지 않는다. 서버에는 SHA256 해시만 저장한다.
같은 토큰을 재사용해야 같은 게스트 계정으로 복원된다.

이는 로컬 시연용 게스트 자격 증명이다. 이메일 로그인·복구·토큰 회전·다중 기기 계정 연결은 아직 없다.
토큰을 잃으면 계정을 복구할 수 없다. 다른 토큰은 별도 계정이므로 사람 단위의 중복 가입/보상 남용 방지 수단은 아니다.
차량과 모바일에 이 장기 토큰을 QR로 전달하지 않는다. 아래 만료 세션 API로 참여를 위임한다.

## API

| 메서드 | 경로 | 동작 |
|---|---|---|
| GET | /health | 서버 상태, 인증 불필요 |
| PUT | /api/account | 최초 등록 또는 기존 계정 복원. 기본 11색 지급 |
| GET | /api/palette | 자신의 저장된 팔레트 조회 |
| POST | /api/sessions | 계정 소유자만 연결 세션 생성 |
| POST | /api/sessions/join | 참여자 토큰과 JSON {"code":"연결코드"}로 참여 |
| GET | /api/session/palette | 참여자 토큰으로 세션 소유자 팔레트 조회 |
| DELETE | /api/sessions/{id} | 소유자만 세션 종료 |
| GET | /api/session/artwork | 참여자 권한으로 공유 계정의 저장 작품 조회 |
| PUT | /api/session/artwork | strokes, legacyRegions, revision 형식으로 브러시 획 저장 |

팔레트 정상 응답은 colors를 포함한다.
오류는 {"error":"코드"} 형식이다. 인증 실패401, 잘못된 입력400,
큰 요청413, 없는 경로404를 반환한다.
지역 수집 API는 클라이언트가 임의 지급하지 못하도록 아직 노출하지 않는다.

## 검증

`npm.cmd run check`: 파일 DB 재개방 후 보상/색 복원, 등록 재시도,
Windows Codex 샌드박스에서 localhost 연결이 EACCES로 막히면 네트워크 실행 권한이 필요하다.

## 차량·모바일 연결 세션

차량 계정으로 POST /api/sessions를 호출하면 id, code, joinExpiresAt, expiresAt을 받는다.
연결 코드는 96비트 난수의 hex24자이며 신규 참여 유효 시간은5분, 세션 전체 수명은8시간이다.
시간은 서버 기준 Unix 밀리초다. 소유자가 새 세션을 만들면 이전 세션은 종료된다.

모바일은 계정 장기 토큰과 별개의 난수32바이트 참여자 토큰을 생성·보관하고,
Authorization 헤더에 사용하여 join API로 코드를 보낸다. 참여 계정을 새로 만들 필요가 없고 보상도 지급하지 않는다.
성공한 참여자는 같은 코드·토큰으로 재시도할 수 있다. 신규 참여 코드가 만료돼도 기존 참여자의 세션은 전체 만료까지 유지된다.
다른 세션에 참여할 때는 새 참여자 토큰을 만든다. 참여자 권한은 공유 팔레트 조회·개인 색 해금·작품 조회/저장이며,
세션 발급·종료 권한은 없다.

코드와 참여자 토큰 원문은 서버에 저장하지 않고 해시만 저장한다.
다른 계정은 세션 종료를 요청할 수 없다. 종료/전체 만료 시 참여자의 조회·차감을 모두 차단한다.
잘못된 코드·만료·종료된 초대는 INVALID_SESSION(400), 이미 다른 세션에 사용한 참여자 토큰은 PARTICIPANT_IN_USE(409),
소유하지 않은 세션 종료는 SESSION_NOT_FOUND(404)다.

모바일 웹은 같은 서버의 /에서 제공한다. QR 이미지 생성·Android 연결·실제 정차 확인은 아직 구현하지 않았다.
지금의 세션 API는 로컬 개발용이며 차량 연동 시 정차 확인 후 연결 코드를 표시해야 한다.
배포 서버/HTTPS/사용자 로그인·요청 속도 제한·만료 데이터 정리는 후속 작업이다.

## 작품 저장

작품은 strokes 배열로 저장한다. 예: {"strokes":[{"tool":"paint","color":"#2196F3","width":12,"points":[[10,20],[30,40]]}],"legacyRegions":{},"revision":0}.
tool은 paint/erase, width는1~60, 좌표는600×400 내부 유한수만 허용하며 해금된 HEX 색만 저장할 수 있다.
최대1000획·총20000점·획당2000점·요청512KiB로 제한한다. 다른 API 요청은4KiB 제한을 유지한다.
기존 regions 형식 작품은 GET에서 legacyRegions로 읽으며 삭제하지 않는다. legacyRegions는 기존 데이터와 같아야 하므로 새 영역 채우기를 등록할 수 없다.
GET의 초기 revision은0이다. PUT마다 서버 트랜잭션에서 기존 revision을 대조한 후1씩 증가시킨다.
다른 기기가 먼저 저장했다면 ARTWORK_CONFLICT(409)를 반환하고 기존 작품은 유지한다.
획·좌표·색·버전 형식 오류는 INVALID_ARTWORK(400)다. 작품은 세션이 아닌 계정에 귀속되며 세션이 끝나도 남는다.

## 스티커와 재방문 일기 준비

core/journey.mjs의 순수 함수는 서버 연결 전 기반 규칙이다. 방문 증거는 서버에서 검증한 값만 전달해야 한다. 스티커 지급 정책은 미정이며 API를 노출하지 않았다.
스티커 보유는 콘텐츠 ID로 중복을 막고 일기 배치 인스턴스와 분리한다. 배치의 x/y/width/height는 기존 600×400 좌표계를 사용하고 보유 자산·중복 인스턴스 ID·범위를 검증한다. 가로 폭과 세로 높이는 독립적이다.
재방문 선택 함수는 같은 가족/자녀의 이전 여행 기록만 조회하며 빈 기록·삭제 기록·미래 기록·한국 날짜 기준 당일 기록은 제외한다. 최근 일기 한 건을 안내하고 방문별 전달 이력이 있으면 반복 안내하지 않는다. 방문 ID는 같은 방문 중 안정적으로 유지해야 한다.
가족/자녀 인증, 실제 지역 진입 판정, 일기·스티커 DB, 전달 이력의 원자적 저장과 재알림 정책, 알림 발송은 아직 미구현이다. 기존 artworks 테이블을 일기로 가장하거나 자동 변환하지 않는다.

## 경주 모의 방문 시험
`PALETTE_MOCK_LOCATION=1`로 서버를 시작하고 가족 세션에 연결한다. 웹 메뉴의 색깔·스티커 사전에서 **경주 진입·체류 모의 경로 실행**을 누르면2분 경로를 가속 전송한다. 경주 색3개/스티커2개가 가족에 지급된다. 웹과 차량 가족 연결 화면에서5초 내 목록을 갱신한다. 기존 개발용 스티커 해금은 별개다.

- `GET /api/session/visits`: 모의 정책/활성화 여부/가족 보상 이력.
- `POST /api/session/visits/mock`: `{source:"simulation",latitude:35.8347,longitude:129.219,timestamp:0}` 형식. timestamp는 모의 경로의 밀리초 시각이며 같은 가족에서 증가해야 한다.
- 시연 중심 반경5km 안에서120초 체류, 표본 간격30초 이하. 이탈/긴 공백은 초기화한다. 재진입/재접속/서버 재시작으로 중복 지급하지 않는다.
- 실제 행정구역/실방문 인증/정차 API 연동이 아니다. 실제 Pleos 연동은 다음 단계다.
