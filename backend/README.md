# 로컬 백엔드

Node24 이상에서 저장소 루트의 `npm.cmd start`로 실행한다.
주소는 http://127.0.0.1:3000 이며 외부 네트워크에는 바인딩하지 않는다.
SQLite 데이터는 backend/data/에 저장되고 Git에서 제외된다.

## 계정 식별

클라이언트는 암호학적 난수32바이트를 소문자 hex64자로 생성해 안전하게 보관하고,
모든 계정 API에 `Authorization: Bearer <토큰>` 헤더로 보낸다.
토큰은 URL에 넣지 않는다. 서버에는 SHA256 해시만 저장한다.
같은 토큰을 재사용해야 같은 게스트 계정으로 복원된다.

이는 로컬 시연용 게스트 자격 증명이다. 이메일 로그인·복구·토큰 회전·다중 기기 계정 연결은 아직 없다.
토큰을 잃으면 계정을 복구할 수 없다. 다른 토큰은 별도 계정이므로 사람 단위의 중복 가입/보상 남용 방지 수단은 아니다.
차량과 모바일에 이 장기 토큰을 QR로 전달하지 않는다. 추후 만료 세션으로 참여를 위임한다.

## API

| 메서드 | 경로 | 동작 |
|---|---|---|
| GET | /health | 서버 상태, 인증 불필요 |
| PUT | /api/account | 최초 등록 또는 기존 계정 복원. 11색·티켓1장 최초1회 |
| GET | /api/palette | 자신의 저장된 팔레트 조회 |
| POST | /api/palette/personal | JSON {"hex":"#123ABC"}, 티켓1장으로 색 해금 |
| POST | /api/sessions | 계정 소유자만 연결 세션 생성 |
| POST | /api/sessions/join | 참여자 토큰과 JSON {"code":"연결코드"}로 참여 |
| GET | /api/session/palette | 참여자 토큰으로 세션 소유자 팔레트 조회 |
| POST | /api/session/palette/personal | 참여자가 소유자 티켓으로 개인 색 해금 |
| DELETE | /api/sessions/{id} | 소유자만 세션 종료 |
| GET | /api/session/artwork | 참여자 권한으로 공유 계정의 저장 작품 조회 |
| PUT | /api/session/artwork | {"regions":{"sky":"#2196F3"},"revision":0} 형식으로 저장 |

정상 응답은 tickets와 colors를 포함한다. 중복 해금은 티켓을 추가 차감하지 않는다.
오류는 {"error":"코드"} 형식이다. 인증 실패401, 잘못된 입력400,
티켓 부족409, 큰 요청413, 없는 경로404를 반환한다.
지역 수집 API는 클라이언트가 임의 지급하지 못하도록 아직 노출하지 않는다.

## 검증

`npm.cmd run check`: 파일 DB 재개방 후 보상/색 복원, 등록 재시도,
다중 DB 연결에서 티켓 중복 차감 방지, 실제 HTTP 병렬 해금, 인증·입력 검증·계정 분리를 확인한다.
Windows Codex 샌드박스에서 localhost 연결이 EACCES로 막히면 네트워크 실행 권한이 필요하다.

## 차량·모바일 연결 세션

차량 계정으로 POST /api/sessions를 호출하면 id, code, joinExpiresAt, expiresAt을 받는다.
연결 코드는 96비트 난수의 hex24자이며 신규 참여 유효 시간은5분, 세션 전체 수명은8시간이다.
시간은 서버 기준 Unix 밀리초다. 소유자가 새 세션을 만들면 이전 세션은 종료된다.

모바일은 계정 장기 토큰과 별개의 난수32바이트 참여자 토큰을 생성·보관하고,
Authorization 헤더에 사용하여 join API로 코드를 보낸다. 참여 계정을 새로 만들 필요가 없고 보상도 지급하지 않는다.
성공한 참여자는 같은 코드·토큰으로 재시도할 수 있다. 신규 참여 코드가 만료돼도 기존 참여자의 세션은 전체 만료까지 유지된다.
다른 세션에 참여할 때는 새 참여자 토큰을 만든다. 참여자 권한은 공유 팔레트 조회·개인 색 해금이며,
세션 발급·종료 권한은 없다. 해금은 공유 계정 티켓을 차감한다.

코드와 참여자 토큰 원문은 서버에 저장하지 않고 해시만 저장한다.
다른 계정은 세션 종료를 요청할 수 없다. 종료/전체 만료 시 참여자의 조회·차감을 모두 차단한다.
잘못된 코드·만료·종료된 초대는 INVALID_SESSION(400), 이미 다른 세션에 사용한 참여자 토큰은 PARTICIPANT_IN_USE(409),
소유하지 않은 세션 종료는 SESSION_NOT_FOUND(404)다.

모바일 웹은 같은 서버의 /에서 제공한다. QR 이미지 생성·Android 연결·실제 정차 확인은 아직 구현하지 않았다.
지금의 세션 API는 로컬 개발용이며 차량 연동 시 정차 확인 후 연결 코드를 표시해야 한다.
배포 서버/HTTPS/사용자 로그인·요청 속도 제한·만료 데이터 정리는 후속 작업이다.

## 작품 저장

현재 도안의 sky/sun/mountain/field/road 영역만 허용하며 사용 계정에 해금된 HEX 색만 저장할 수 있다.
GET의 초기 revision은0이다. PUT마다 서버 트랜잭션에서 기존 revision을 대조한 후1씩 증가시킨다.
다른 기기가 먼저 저장했다면 ARTWORK_CONFLICT(409)를 반환하고 기존 작품은 유지한다.
영역·색·버전 형식 오류는 INVALID_ARTWORK(400)다. 작품은 세션이 아닌 계정에 귀속되며 세션이 끝나도 남는다.
