# 스티커 자산 출처와 범위

star.svg, heart.svg, cheomseongdae.svg, silla-crown.svg는 이 저장소에서 코드로 새로 작성한 SVG 시안이다.
사용자가 보여준 첨성대 그림의 파일/픽셀/윤곽을 복사하거나 추출하지 않았다. 외부 사진·일러스트 파일을 포함하지 않는다.
첨성대와 금관은 소재이며 현재 도안은 간략화한 창작 표현이다. 고증을 위한 정확한 재현도나 박물관 공식 상품이 아니다.

첨부 이미지 자체의 제작자·라이선스는 미확인이다. 해당 파일을 나중에 그대로 쓰려면 별도로 이용 범위를 확인한다.
저작물 이용 조건 참고: https://www.findcopyright.or.kr/user/trust/markup/markup/DSC-AD-001-01.do
신라 금관 소재 참고: https://www.museum.go.kr/MUSEUM/contents/M0502000000.do?relicId=752&schM=view&searchId=search
외부 자료의 사진을 자산으로 가져오지는 않았다.

현재는 사전 미리보기 자산이다. 페이지 배치·폭/높이 조절·저장에는 아직 연결하지 않았다.
