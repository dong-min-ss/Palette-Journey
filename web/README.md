# 동승자 모바일 웹

## 개정 그림일기 기능

가족 안에서 자녀 별명·여행·그림일기를 만들고 여러 페이지를 추가/선택할 수 있다.
빈 캔버스 또는 여행길 기본 도안을 골라 브러시 그림과 글을 남긴다.
글만 쓰거나 그림만 그려도 저장된다. 제목/그림/글은 입력 중지1.2초 후 자동 저장하며 페이지별 임시 기록도 유지한다.
기존 작품은 첫 일기 첫 페이지로 가져오고 원본은 보존한다. 저장 모델/API는 backend/DIARIES.md에 설명한다.
현재 스티커·음성은 미구현이며 지역 스티커를 임의 지급하지 않는다.

저장소 루트에서 Node24 이상으로 `npm.cmd start` 실행 후 http://127.0.0.1:3000 을 연다.
차량 세션 생성 API가 발급한24자리 코드를 입력하면 참여자 토큰을 브라우저에 생성·보관한다.
현재 Android 앱에는 코드 발급 버튼이 없으므로 연결은 개발용 API로 발급한 코드로 검증한다.

## 구현 범위

- 코드로 세션 참여, 새로고침 후 연결 복원, 이 브라우저에서 연결 나가기.
- 기본11색 및 해금 색 표시, 티켓을 사용한 개인 색 추가.
- 여행길 풍경 도안1개, 손가락/펜/마우스가 지나가는 경로만 칠하는 Canvas 브러시.
- 브러시 굵기2~48, 지우개, 실행 취소·다시 실행. 도안 선은 별도 SVG 레이어라 지워지지 않는다.
- 서버 저장·불러오기, 새로고침 후 작품 복원, 저장하지 않은 변경 이탈 확인.
- 다른 기기가 먼저 저장한 경우409 충돌 메시지를 표시하고 현재 그림을 유지한다.
- 좁은 휴대폰 화면에서도 팔레트와 버튼이 줄바꿈된다.

그림은 일기 페이지별 순서 있는 획(tool/color/width/points)으로 저장된다. 만료된 세션으로는 읽거나 저장할 수 없다.
영역 전체 채우기 기능은 제거했다. 기존에 저장된 영역 색은 보존되며 이후 브러시·지우개로 이어 작업할 수 있다.
현재 브러시는 도안 경계에 자동으로 가두지 않는다. 선을 넘어 칠할 수도 있고 지우개로 수정할 수 있다.
좌표계는600×400이며 화면 크기에 맞춰 입력을 변환한다. 최대1000획·총20000점·획당2000점이다.
새 세션으로 같은 계정에 참여하면 저장된 작품을 다시 불러올 수 있다.
개인 색 추가는 현재 색상 선택기로 제공한다. 사진 업로드·스포이드는 후속 기능이다.
자동 실시간 갱신은 아직 없으며 불러오기 버튼으로 최신 팔레트·작품을 가져온다.

## 여행 그림일기 개정과 현재 한계

지역 스티커는 방문 업적 보상으로 획득하고 일기에 반복 배치하며 크기·비율을 조절하는 방향이다. 구체적인 획득 조건은 미정이다. 재방문 시 과거 일기를 다시 읽는 안내도 계획한다.
현재 웹은 브러시 컬러링과 수동 저장까지 구현돼 있다. 스티커 편집·여러 일기·글·음성·재방문 안내·백그라운드 푸시는 아직 없다. core/journey.mjs의 규칙은 웹에 연결하지 않았고 기존 작품 형식은 유지한다.

## 기기 연결

현재 서버는 localhost에만 바인딩되므로 이 PC의 브라우저에서 검증한다.
휴대폰 실기기 접속·HTTPS·QR 스캔·실제 차량 정차 확인은 아직 구성하지 않았다.
참여자 토큰은 localStorage에 저장되며 해당 브라우저 데이터 삭제 시 사라진다. 장기 계정 토큰은 저장하지 않는다.
연결 나가기는 브라우저 자격 증명을 지우는 동작이며 전체 세션 종료는 소유자 API에서 수행한다.
