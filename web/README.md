# 그림일기 공통 화면

이 폴더는 모바일 웹과 안드로이드 폰 보조 앱이 함께 사용하는 그림일기 화면이다. 폰 보조 앱 실행과 APK 경로는 [PHONE_DEMO.md](../PHONE_DEMO.md), 전체 여행 시연은 [MVP_FLOW.md](../MVP_FLOW.md)를 참고한다.

## 작성 흐름

차량 또는 기존 가족 참여자가 발급한 24자리 코드로 같은 가족에 연결한다. 기기별 참여자 토큰은 localStorage에 보관하며 서버에서 가족 권한을 확인한다. 연결 나가기는 이 기기의 자격 증명을 지우며 가족 전체 기록은 삭제하지 않는다.

가족 안에서 자녀 별명·여행·그림일기를 만들고 여러 페이지를 추가·선택한다. 빈 종이에서 그림·스티커·선택적인 짧은 글을 작성하고, 그림 아래에서 목소리까지 녹음한다. 그림은 입력 중지 1.2초 후 서버에 자동 저장하고 기기별 임시 기록도 유지한다. 녹음 시작 전에는 현재 그림 저장을 완료한다.

녹음은 보호자 동의 → 목소리 녹음하기 → 녹음 마치기 → 미리 듣기 → 이 그림에 목소리 저장 순서다. 현재 페이지에 바로 저장하므로 다른 기기에서 파일을 고르거나 페이지를 다시 지정하지 않는다. 준비된 질문은 보호자가 직접 읽거나 자유롭게 대화하는 참고 문구다. 실제 글레오 AI 자유 대화는 후속 기능이다.

## 그림과 여행책

좌표계 600×400, 최대 1000획·총 20000점·획당 2000점이다. 부분/획 지우개, 취소/다시 실행, 기본 11색·보유 지역색·개인 색, 기본/보유 스티커의 배치·이동·모서리 크기 조절·개별 색칠·삭제를 지원한다. 잠긴 지역색은 서버에서도 사용을 거절한다. 개발용 해금은 실제 방문 보유와 구분한다.

여행책 메뉴는 페이지 목록·새 페이지 만들기·저장된 기록 불러오기·추억 다시 보기·연결 나가기를 간격과 구분선으로 나눈다. 날짜와 지역이 지정된 과거 그림은 모의 재방문 안내 대상이 된다. 실차 도착·백그라운드 푸시를 구현한 것으로 표시하지 않는다.

## 음성 보관

페이지별 1개, 최대 2분/2MiB. 시작·다음 질문·일시정지·이어가기·종료·미리 듣기·명시적 저장·재생·삭제를 지원한다. WebM/Opus, Ogg/Opus, MP4 중 MediaRecorder 지원 형식을 선택한다. 외부 AI로 음성을 보내지 않으며 가족 세션으로 접근한다. 안내 동의와 실제 보호자/아동 인증은 구분한다.

그림과 음성은 별도 버전으로 충돌을 검사한다. 저장 실패 시 현재 녹음을 유지해 같은 화면에서 재시도할 수 있다. 일반 브라우저는 파일 내려받기도 지원하며 보조 앱에서는 이 버튼을 숨긴다. 앱 종료·새로고침 후 미저장 녹음 복구는 지원하지 않는다. 화면을 벗어나면 녹음을 일시정지하고 자동 재개하지 않는다.

차량의 기존 대화 업로드도 유지한다. 현재 그림의 새로운 녹음은 약 5초 갱신으로 확인하며, 재생 중·녹음 중·미저장 음원이 있으면 자동 교체하지 않는다. 차량 녹음은 재합성 질문과 답변 원음을 하나의 파일로 들려주며 질문 원음과 다를 수 있다.

## 접속

Node 24 이상에서 저장소 루트의 `npm.cmd start`를 실행한다. PC 브라우저는 http://localhost:3000 을 사용한다. LAN HTTP 브라우저는 그림 작성·동기화가 가능하지만 마이크가 제한된다. 폰 보조 앱 시연은 adb reverse와 localhost를 사용하므로 인증서 설치가 필요 없다. 서버가 켜져 있어야 동기화할 수 있다.
